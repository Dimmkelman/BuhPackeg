# Карманная бухгалтерия

Учёт личных доходов и расходов в одном HTML-файле: итоги месяца, график трат по дням, лимиты по категориям, правило 50/30/20, редактирование операций и экспорт в CSV.

Данные хранятся только в браузере пользователя (localStorage) и никуда не отправляются. Очистка данных сайта удалит записи, поэтому периодически делайте экспорт в CSV.

Открыть локально: дважды щёлкните `index.html`.
